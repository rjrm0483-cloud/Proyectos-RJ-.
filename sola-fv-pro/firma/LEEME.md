# Llave de firma de prueba

`debug.keystore` es la llave con la que GitHub firma el APK. Debe ser siempre la misma: si cambia, Android no deja instalar la actualización encima de la app ya instalada.

Es una llave de prueba (contraseña `android`, alias `androiddebugkey`), la misma que usa la app de Inspección. Sirve para instalar el APK directamente, no para Google Play.
